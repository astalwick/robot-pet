Custom-built, not a purchased product. Expected materials:

## Personality / Agency Phases

The personality phases primarily use the audio/video hardware from Body Phase 1 and body capabilities exposed by later body phases.

- Personality Phase 1 uses the Body Phase 1 microphone and speaker for STT -> cloud LLM -> TTS.
- Personality Phase 2 uses Body Phase 0 motion for tiny bounded tools.
- Personality Phase 5 may use the LED face listed under Body Phase 7+ if expression work pulls that hardware forward.
